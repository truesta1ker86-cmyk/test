# Свёрнутое меню и множественный выбор — 26.10.2026

Пользователь уточнил: сворачивание сохранить, в узкой панели показывать только иконки. Работа выполнена напрямую с кодом, без скачанных скиллов.

## Меню

- В свёрнутом режиме скрываются подписи пунктов, названия групп, счётчики, стрелки и вложенные разделы. Иконки не сжимаются.
- Кнопки имеют aria-label и title с полным названием раздела. Переходы по иконкам обычных разделов и групп работают; подразделы доступны в полном меню и на страницах разделов.
- Логотип центрируется в панели 80 px. Кнопка раскрытия расположена отдельно у её края, не теснит логотип; подпись кнопки соответствует текущему состоянию.
- После сворачивания на компьютере мобильное меню открывается с полными названиями. Исправлены передача состояния collapsed в навигацию и приоритет CSS для одновременно collapsed/menu-open.

## Множественный выбор

Установленный PrimeNG поддерживает Select с multiple. Переписывать общий компонент или менять зависимости не потребовалось.

Добавлены проверки реальных контролов вместо только прямого вызова updateValue:

- добавление второго значения без потери первого;
- снятие отдельного значения и очистка крестиком;
- поиск варианта с сохранением ранее выбранных значений;
- запрет выбора недоступного варианта;
- применение двух чекбоксов фильтра столбца и восстановление выбора при повторном открытии;
- сохранение выбранных значений при получении другой страницы удалённых вариантов.

В браузере на синтетическом loopback-стенде подтверждены:

- два бренда Docke / Grand Line одновременно в параметре brand и оба отмечены при повторном открытии списка;
- общий сброс очищает массив брендов;
- два значения схемы fbs / fbo передаются одним массивом column_filters.scheme.values;
- повторное открытие показывает оба чекбокса, «Отмена» сохраняет применённый отбор;
- свёрнутое меню имеет ширину 80 px, main начинается с 80 px, видимого обрезанного текста в навигации нет;
- раскрытие, переход по иконке остатков и полный мобильный drawer после desktop-collapse работают;
- в мобильном режиме 768 px документ не выходит за ширину экрана;
- консоль без предупреждений и ошибок.
