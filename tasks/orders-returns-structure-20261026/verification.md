# Результат: отдельные страницы Orders / Returns

26 октября 2026. Выполнено локально в репозитории `test/`, ветка `codex/unify-tables-20261020`.

- Страницы используют отдельные `OrdersComponent` и `ReturnsComponent`; у возвратов свой `ReturnListComponent`.
- Компоненты объявлены в `pages/orders/orders.module.ts` и `pages/returns/returns.module.ts`. Внутри папок компонентов этих страниц модулей нет.
- Общая панель `DataTableToolbarFilterComponent` находится в `shared/data-table-filter/components/data-table-toolbar-filter/` и экспортируется через существующий `DataTableFilterModule`.
- Настройки полей и сортировок передают страницы. Общая панель не импортирует код или стили из страниц.
- Фильтр столбца `DataTableFilterComponent` и накопленные пользовательские правки сохранены.
- HTTP-контракты и backend не менялись. TypeScript ListQuery использует общую структурно эквивалентную форму значения фильтра.
