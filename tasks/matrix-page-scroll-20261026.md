# Прокрутка распределения между складами — 26.10.2026

Запрос: прокручивать страницу распределения целиком, освободить матрицу от отдельного маленького вертикального окна и спрятать быстрые отборы под одну кнопку.

## Реализация

- У allocation-scroll убраны фиксированная высота и минимальная высота. Матрица растёт по строкам, вертикальный скролл принадлежит page-content.
- Inline overflow внутреннего контейнера PrimeNG отключён для allocation-scroll, чтобы не появлялась дополнительная область прокрутки.
- Добавлена отдельная нижняя горизонтальная полоса, синхронизированная с матрицей. Она остаётся доступной при просмотре строк; не требуется спускаться к последней строке ради перехода к дальним складам.
- MatrixPageScrollDirective удерживает заголовок у верхней границы области страницы и ограничивает его концом таблицы. Артикул остаётся закреплён по горизонтали. Обработчики сгруппированы через requestAnimationFrame, наблюдение размеров и подписки очищаются при выходе.
- Большой контейнер матрицы не создаёт лишнюю остановку Tab; поля и горизонтальная полоса сохраняют клавиатурный доступ.
- Показатели и быстрые условия перенесены в существующий app-popup-button «Быстрый отбор» рядом с остальными фильтрами. Состояния rules_status / distribution_status и их комбинации сохранены.
- Объявление директивы добавлено в существующий AllocationMatrixModule; PopupButtonModule подключён в модуле страницы. Новых модулей компонентов нет.
- Удалены ставшие ненужными стили карточек показателей; остальной CSS страницы сохранён.

Расчёты, доли, кратность, защита черновиков, работа с магазинами и серверные контракты не менялись.
