# Компактные фильтры и сводка остатков — 26.10.2026

По запросу пользователя уменьшено окно фильтра столбца и убраны большие карточки показателей в остатках.

## Изменения

- Общий фильтр столбца: ширина 300 px вместо 360, ограничение высоты 420 px с учётом размера окна, меньшие отступы, поля и кнопки по 30 px.
- Список вариантов ограничен по высоте, чекбокс и значение находятся в одной строке. Исправлен конфликт с общими стилями workspace, которые растягивали поля до 38 px и располагали подпись под чекбоксом.
- Оператор и текстовое условие размещены рядом. Множественный выбор, поиск вариантов, числовые границы, пагинация и действия «Сбросить / Отмена / Применить» сохранены.
- Сводка остатков использует существующий компактный вариант постоянно, а не только в матрице. Большие пояснения под показателями убраны; сами значения и действия быстрых отборов сохранены.
- Изменения касаются CSS и шаблона. Расчёты, API и сохранённые правила не менялись.
